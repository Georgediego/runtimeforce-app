# 🚀 RuntimeForce

**RuntimeForce** — это специализированная среда разработки и платформа оркестрации (AI Runtime Environment) для локальной и SSH-разработки. 

Инструмент позволяет вам общаться с единым умным интерфейсом, пока нейросети (LLM) выполняют рутинную работу с кодом и терминалом прямо в вашем рабочем окружении.

---

## 💡 Философия продукта

* **Единый интерфейс:** Вы взаимодействуете с логикой RuntimeForce. Модели (ChatGPT, Claude, Gemini, Groq, Ollama) — лишь заменяемые исполнители задач.
* **Фокус на терминале:** В отличие от обычных AI-редакторов, RuntimeForce спроектирован вокруг продвинутой работы с PTY-терминалом, распределенной средой и удаленными серверами по SSH.
* **Суверенитет данных (Zero Trust):** Весь ваш исходный код, история чатов, SSH-доступы и персональные Git-токены хранятся **строго локально** на вашей машине и не передаются на сторонние серверы.

---

## 🏗️ Как это устроено

* **runtimeforce-app (Ваш клиент):** Легковесный локальный рантайм на FastAPI, который управляет Monaco Editor, терминалом xterm.js, деревом файлов и локальным оркестратором моделей.
* **runtimeforce-server (Наше облако):** Облачный stateless-слой, который отвечает только за авторизацию, контроль подписок (через Paddle) и безопасное проксирование запросов к коммерческим ИИ-моделям в Pro/Expert режимах.

---

## ⚡ Быстрый старт (Установка клиента)

Вы можете развернуть клиент `runtimeforce-app` локально на рабочей машине или на своем приватном dev-VPS.

### Требования:
* Python 3.11 или выше
* Установленный Git

### Шаги по установке:

1. Клонируйте репозиторий с клиентом:
   
   git clone https://github.com/your-repo/runtimeforce.git
   cd runtimeforce/runtimeforce-app

2. Перейдите в директорию приложения:
   
   cd runtimeforce-app

3. Создайте виртуальное окружение и установите зависимости:

python -m venv venv
source venv/bin/activate  

# Для Windows: venv\Scripts\activate

pip install -r requirements.txt

4. Запустите приложение:

run.sh
