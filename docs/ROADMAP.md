# RuntimeForce Roadmap

This roadmap separates the product's current direction from features that should not be presented as already shipped. Priorities may change as feedback and implementation capacity evolve.

## Current product focus

- Reliable project-scoped Workspace and SSH resolution.
- Project-scoped Git status, diff, commit, branches, push and pull.
- Clear project switching with no cross-project workspace fallback.
- Stable installation and update flows for Linux, macOS and Windows.
- Accurate plan entitlements and transparent plan limits.
- Better onboarding for local models and direct BYOK providers.
- Documentation for architecture, security, workspace setup and GitHub workflows.

## Planned improvements

- Stronger protection for local application secrets and master-key lifecycle.
- More explicit security controls for local database backups and recovery.
- More comprehensive automated tests for project switching and concurrent project operations.
- Improved first-run diagnostics for Ollama, LM Studio and provider connectivity.
- More detailed GitHub repository and SSH troubleshooting guidance.
- Public, reproducible performance benchmarks before publishing latency claims.

## Transparency

Roadmap items are intentions, not release commitments. A feature should be described as available only after it is implemented, tested and included in a stable release. Performance claims should be backed by reproducible measurements on documented hardware and models.
